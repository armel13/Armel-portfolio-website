# T. Armel Fahlevi - Personal Portfolio

This is a high-quality, modern personal portfolio website for T. Armel Fahlevi, a professional data analyst and AI enthusiast.

## Features

- **Responsive Design**: Built with Tailwind CSS to ensure mobile and desktop compatibility.
- **Dark/Light Mode**: User-toggleable theme with automatic system preference detection.
- **Glassmorphism**: Premium glass-like cards and background blurs.
- **Animations**: Smooth scroll reveal animations.
- **Sections**:
  - Hero with strong CTA
  - About Me
  - Skills
  - Experience
  - Projects
  - Certifications
  - Contact Form

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS via CDN)
- JavaScript (Vanilla)
- FontAwesome (Icons)
- Google Fonts (Inter)

## How to Run

Simply open `index.html` in your favorite web browser, or use a local server:

```bash
python3 -m http.server 8000
```
